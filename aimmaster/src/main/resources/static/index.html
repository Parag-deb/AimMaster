About AimMaster

AimMaster is a real-time multiplayer aim-training game built with Spring Boot, WebSocket/STOMP, and MediaPipe hand tracking.

Players join rooms, compete in timed matches, and track their progress through match history and live leaderboards.

Version: 1.0.0

Stack: Java 17, Spring Boot 3, H2, JWT, SockJS/STOMP, MediaPipe Hands
